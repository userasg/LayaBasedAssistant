# research-workflow

1. Delegate searching to the `researcher` subagent; you have no search tool yourself.
2. Ask for 3 to 5 sources per question and require the URL for each claim.
3. Save long findings to `/workspace/notes/<topic>.md` instead of keeping them in the conversation.
4. Cross-check any number or date that appears in only one source.
5. Return under 300 words with the sources listed. If the user wants more, point at the notes file.
